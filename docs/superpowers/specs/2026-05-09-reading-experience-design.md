# 阅读功能 UI/UX 优化设计文档

**日期**: 2026-05-09
**目标用户**: 小学高年级至初中（4-8年级，10-14岁）
**设备**: iPad 为主，横竖屏自适应
**方案**: 沉浸式阅读体验增强（方案1）

---

## 1. 设计理念

### 1.1 核心目标
让青少年在 iPad 上阅读时感到"这个 App 很懂我"——流畅、有质感、不幼稚但有趣。

### 1.2 设计锚点
- **Apple Books + Notion + 一点点游戏感** = 干净、有层级、但不冰冷
- 保持现有森林绿 + 米白色调，增加**材质层次**（轻微毛玻璃、纸张纹理阴影）
- 所有过渡动画使用 `cubic-bezier(.16, 1, .3, 1)` 缓动，营造弹性质感
- 触控目标保持 >= 48pt，边缘留白更大气

### 1.3 iPad 专属优化
- 横屏：充分利用三栏布局（目录 | 内容 | 设置/笔记）
- 竖屏：底部悬浮工具栏，手势驱动（轻扫翻页、双指缩放字体）
- 支持 Split View 和 Slide Over 的优雅降级

## 2. 文章列表页（/reading）

### 2.1 当前问题
网格卡片信息密度适中，但发现感较弱，像静态货架。

### 2.2 优化内容

| 元素 | 优化前 | 优化后 |
|------|--------|--------|
| 顶部区域 | 简单标题 + 语言切换 | **个性化欢迎区**（显示"本周已读 X 篇"）+ 语言切换融入 Segmented Control |
| 分类筛选 | 横向 pill 排列 | **可横向滑动的分类轨道**，当前选中项有下划线动效 |
| 文章卡片 | 标准卡片 | **杂志风卡片**——大封面图、标题用 reading-zh/reading-en 字体、底部进度条（如果读过）|
| 空状态 | 纯文字 | **插画 + 引导性文案** + 推荐按钮 |
| 加载状态 | 脉冲骨架屏 | **翻页动画骨架**（更有阅读感）|

### 2.3 新增交互
- 卡片**长按预览**（Quick Look 风格，显示文章开头 + 难度 + 预估时间）
- 下拉刷新时顶部显示"正在发现新文章..."配旋转的书本图标
- 已读文章卡片**右下角显示完成徽章**（小圆章，hover/按压时展开显示分数）

### 2.4 保留功能
- 语言切换（zh/en）
- 分类筛选
- 文章数据接口（/api/reading/articles）
- 阅读状态同步（reading_assignments 表）

## 3. 阅读器沉浸体验（/reading/[id]）

### 3.1 保留的重要功能

| 功能 | 保留原因 | 优化方式 |
|------|----------|----------|
| TTS 朗读 | 低龄用户和语言学习刚需 | 播放时增加**声波可视化条**，朗读句子高亮从"底色块"升级为**下划线流光** |
| 拼音标注（中文） | 中文学习核心辅助 | ruby 排版优化，拼音字号从 0.45em 提升到 **0.55em**（iPad 更清晰） |
| 点击查词 | 即时词汇学习 | 弹窗从固定位置改为**就近弹出**（靠近点击词），增加音标/发音按钮 |
| 三主题切换 | 护眼和偏好 | 新增**自动主题**（随系统 dark mode）+ sepia 纸张纹理更细腻 |
| 字体/行高调节 | 个性化阅读 | 右侧面板改为**底部滑出式控制板**（竖屏更顺手） |
| 横屏翻页 | iPad 横屏核心体验 | 翻页动画从 translateX 升级为 **3D page-curl 效果**（CSS perspective） |
| 竖屏滚动 | 纵屏默认 | 增加**段落渐入**动画（滚动时新段落淡入） |
| 阅读进度 | 断点续读 | 进度条从顶部细线改为**左侧章节导航**中的可视标记 |
| 书签 | 重点回顾 | 增加**书签列表浮层**（从工具栏可快速跳转） |
| 插图 | 增强理解 | 从 collapsible 展开改为**轻点放大**（Lightbox 风格） |

### 3.2 顶部导航栏重构

- 初始显示，向下滚动时**自动收起**（向上滚动恢复）
- 左侧：仅保留 <- 图标（更克制）
- 右侧：TTS 按钮 + 书签 + 更多（...）
- 整体改为**毛玻璃效果**（backdrop-blur + 半透明背景）

### 3.3 内容区排版升级

- 中文文章：使用 `font-reading-zh`（LXGW WenKai），行高增加到 **1.9**
- 英文文章：使用 `font-reading-en`（Fraunces），增加**首字下沉**（Drop Cap）效果
- 段落间距从 `space-y-4` 提升到 **`space-y-6`**
- 文章开头增加**装饰性引号**和作者/来源信息

### 3.4 底部阅读工具栏（竖屏新增）

屏幕底部悬浮的**胶囊形工具栏**：
- 字体大小滑块（左右拖动）
- 主题切换（轻点循环）
- 目录/进度
- 笔记
- 支持上下轻扫展开/收起

### 3.5 翻页动效升级（横屏）

- 当前：CSS translateX，平移切换
- 优化：使用 CSS `perspective` + `rotateY` 实现**纸张卷曲效果**
- 增加**翻页音效**（可选，轻脆的纸张声）
- 页面边缘增加**阴影层次**，模拟真实书籍厚度

### 3.6 阅读手势增强

| 手势 | 动作 |
|------|------|
| 单指左右轻扫 | 翻页（横屏）/ 章节跳转（竖屏） |
| 双指捏合/张开 | 字体大小调整 |
| 单指长按 | 选中文字（查词/高亮/笔记） |
| 顶部边缘下滑 | 显示完整导航栏 |
| 双击 | 切换日间/护眼主题 |

## 4. 测验体验优化（QuizView）

### 4.1 设计方向
从"考试"变成"挑战"。

### 4.2 视觉升级

| 元素 | 优化前 | 优化后 |
|------|--------|--------|
| 进度条 | 顶部细条 | **环形进度**（题目编号在环内，随答题旋转） |
| 题目卡片 | 白底黑字 | **毛玻璃卡片**，选项有 hover/active 的**液态填充**效果 |
| 选项按钮 | 方框 + ABCD | **圆角大按钮**，选中时从中心向四周**波纹扩散**确认 |
| 题型标签 | 小灰标签 | **彩色图标 + 文字**（主旨题=靶心，细节题=放大镜，推理题=灯泡） |
| 难度星标 | 文字"星星" | **动态火焰条**（1星=微火，3星=烈焰） |

### 4.3 交互增强

**答题反馈即时化**：
- 选择答案后不等 500ms 自动跳转：
  - 正确：选项**绿光脉冲** + 对勾动画 + 鼓励语句浮现
  - 错误：选项**红色微震** + 显示正确答案**金色高亮** + 提示"再想想~"
- 1.5s 后自动进入下一题

**连击系统**：
- 连续答对 3 题触发 **"火焰 x3" 浮层**
- 连击中断时温和提示

**题目切换动效**：
- 当前题**向左滑出**，新题**从右滑入**
- 使用 `cubic-bezier(.16, 1, .3, 1)` 缓动

### 4.4 保留功能
- 自动提交、计时统计、与后端 API 交互逻辑
- 答题结果数据结构不变

## 6. 交互手势与动效规范

### 6.1 全局手势地图

| 场景 | 手势 | 动作 |
|------|------|------|
| 列表页 | 下拉 | 刷新，顶部书本图标旋转 |
| 列表页 | 长按卡片 | Quick Look 预览文章 |
| 列表页 | 左右滑动卡片 | 快速标记已读/收藏 |
| 阅读器竖屏 | 左右轻扫 | 段落级导航 |
| 阅读器竖屏 | 双指捏合 | 字体大小实时调整 |
| 阅读器竖屏 | 长按文字 | 查词/高亮/笔记菜单 |
| 阅读器横屏 | 左右轻扫/点击边缘 | 3D 翻页 |
| 阅读器横屏 | 顶部下滑 | 显示导航栏 |
| 测验 | 左右滑动 | 题目切换（已答可回顾）|
| 全局 | 摇晃 iPad | 撤销最近一次操作（趣味彩蛋）|

### 6.2 动效规范

- **缓动**：
  - 入场：`cubic-bezier(.16, 1, .3, 1)`
  - 离场：`cubic-bezier(.65, 0, .35, 1)`
- **时长**：
  - 微交互：150ms
  - 页面切换：300ms
  - 复杂动画：600ms
- **物理感**：弹簧效果用于完成反馈，阻尼感用于翻页
