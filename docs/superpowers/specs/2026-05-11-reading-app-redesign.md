# 阅读界面重构设计方案

## 概述

为 homework-tracker 的儿童阅读模块设计专业级阅读体验，以 iPad 横屏双页为核心，兼顾竖屏适配。

**目标用户**：6-12 岁儿童
**核心设备**：iPad（横屏为主）
**设计参考**：微信读书、Kindle、iBooks 阅读体验

---

## 二、顶部栏

### 布局
```
┌──────────────────────────────────────────────────────────┐
│  ← 返回  │     文章标题（超长省略...）     │  G2  │ 🔒 │
└──────────────────────────────────────────────────────────┘
```

### 元素说明
| 元素 | 位置 | 说明 |
|------|------|------|
| 返回按钮 | 左 | 点击返回列表页 |
| 标题 | 中 | 居中，最多 20 字符 + 省略号 |
| 难度标签 | 中右 | G2 样式标签 |
| 录音状态 | 中右 | 录音中显示 🎤 00:45 |
| 方向锁定 | 右 | 锁定/解锁屏幕方向 |

### 样式
- 高度：`h-12`（48px）
- 背景：`backdrop-blur-md bg-[var(--reader-surface)]/80`
- 边框：`border-b border-[var(--reader-border)]`

### 方向锁定功能
- 点击切换锁定/解锁状态
- 锁定状态：🔒 图标高亮
- 解锁状态：🔓 图标灰色
- 锁定时：自动保持横屏，旋转无效
- 解锁时：跟随设备方向自动切换横竖屏

## 三、阅读内容区

### 3.1 双页布局（横屏）

```
┌─────────────────────┐     ┌─────────────────────┐
│                     │     │                     │
│  [正文段落 1]       │     │ [正文段落 3]        │
│                     │     │                     │
│  [正文段落 2]       │     │ [正文段落 4]        │
│                     │     │                     │
│  ┌───────────────┐ │     │                     │
│  │     插图      │ │     │                     │
│  └───────────────┘ │     │                     │
│                     │     │                     │
└─────────────────────┘     └─────────────────────┘
```

#### 样式
- 每页最大宽度：`45rem`（720px）
- 页间距：`gap-6`（24px）
- 内容垂直居中：`items-center justify-center`
- 容器：`h-[calc(100vh-12rem)] overflow-hidden`

### 3.2 单页滚动（竖屏）

- 最大宽度：`max-w-2xl mx-auto`
- 可滚动：`overflow-y-auto`
- 间距：`space-y-4`

### 3.3 插图处理

- 宽度撑满段落
- 高度限制：`max-h-48`
- 点击放大：Modal 全屏查看
- 双页模式下，插图分散到左右页

### 3.4 排版细节

| 属性 | 值 |
|------|-----|
| 正文字号 | `text-lg`（18px）|
| 行高 | `leading-relaxed`（1.625）|
| 段落间距 | `space-y-4`（16px）|
| 拼音字号 | `text-xs`（12px）上方 |
| ruby 拼音对齐 | `display: inline-flex; flex-direction: column` |

## 四、翻页交互

### 组合式交互（横屏）

| 交互 | 触发 | 行为 |
|------|------|------|
| 点击 | 屏幕左侧 30% | 上一页 |
| 点击 | 屏幕右侧 30% | 下一页 |
| 滑动 | 水平滑动 > 50px | 翻页（方向一致）|
| 手势 | 左右滑动 | 翻页 |

### 导航指示器

- 底部居中显示：`◀ ─ ● ─ ● ─ ● ─ ▶`
- 当前页：实心圆点
- 非当前页：空心圆点
- 页码文字：`第 3/8 页`

### 边界保护

- 首页：左翻页区域禁用
- 末页：右翻页区域禁用
- 禁用状态：箭头变灰色

## 六、录音功能（非侵入式）

### 6.1 录音按钮状态

| 状态 | 外观 | 顶部显示 |
|------|------|----------|
| 空闲 | 🎤 录音 | 无 |
| 录音中 | 🎤 01:23（红色脉冲）| 🎤 01:23 |
| 已保存 | ✅ 01:23 | ✅ 01:23 |

### 6.2 录音流程

1. 点击 🎤 → 请求麦克风权限
2. 权限通过 → 后台开始录音
3. 顶部栏显示：🎤 01:23 + 录音波形
4. 再次点击 🎤 → 停止录音
5. 自动保存到本地 + 上传云端
6. 打卡任务自动关联

### 6.3 无时长限制

- 录音时长无上限
- 页面离开时自动停止并保存

### 6.4 停止后处理

```
顶部显示：✅ 已保存 01:23
点击可展开：
  - ▶ 播放录音
  - 📤 提交打卡
  - 🗑️ 删除
```

## 八、技术实现要点

### 8.1 屏幕方向锁定

```typescript
// 锁定横屏
if (screen.orientation?.lock) {
  await screen.orientation.lock('landscape');
}

// 解锁
screen.orientation?.unlock();
```

### 8.2 方向变化监听

```typescript
window.addEventListener('orientationchange', () => {
  setTimeout(() => {
    const isLandscape = window.innerWidth > window.innerHeight;
    setCurrentOrientation(isLandscape ? 'landscape' : 'portrait');
  }, 100);
});
```
